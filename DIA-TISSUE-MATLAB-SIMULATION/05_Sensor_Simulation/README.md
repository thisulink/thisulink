# Experiment 5 - ADXL355-Like Sensor Simulation

## 1. Aim

To simulate an ADXL355-like accelerometer sensor for the DIA-TISSUE mechanical system and evaluate the effects of sensor resolution, bandwidth, noise density, bias, and quantization on the measured acceleration signal.

Note: This experiment is an engineering simulation. The sensor parameters and results are simulation assumptions and are NOT clinical values.

## 2. Objective

The objectives of this experiment are:

1. To simulate an accelerometer measurement from the mechanical acceleration signal.
2. To define a sensor measurement range.
3. To model finite sensor resolution.
4. To introduce sensor noise.
5. To introduce sensor bias.
6. To model sensor bandwidth.
7. To calculate measurement error.
8. To estimate the signal-to-noise ratio.
9. To calculate the quantization step.
10. To evaluate the suitability of the simulated sensor model for the mechanical response.

## 3. Theory

The DIA-TISSUE mechanical model generates a true acceleration signal.

The sensor model converts this ideal acceleration into a simulated measured acceleration by including:

- Sensor range
- Sensor resolution
- Sensor bandwidth
- Noise density
- Bias
- Quantization

The general measured acceleration can be represented as:

a_measured = Quantize(Saturate(a_true + bias + noise))

where:

a_true = true mechanical acceleration

bias = sensor bias

noise = simulated sensor noise

Saturate = sensor range limitation

Quantize = finite-resolution conversion

## 4. Sensor Noise

The RMS noise generated by the sensor model is estimated from:

Noise RMS = Noise Density * sqrt(Bandwidth)

where:

Noise Density = sensor noise density in m/s^2/sqrt(Hz)

Bandwidth = sensor bandwidth in Hz

For this simulation:

Noise Density = 0.000250 m/s^2/sqrt(Hz)

Bandwidth = 150 Hz

Therefore, the model noise RMS is approximately:

Noise RMS = 0.000250 * sqrt(150)

Noise RMS = 0.003062 m/s^2

## 5. Quantization

For a bipolar sensor range of +/- R and a resolution of B bits, the quantization step is:

Quantization Step = (2*R)/(2^B)

For this experiment:

Range = +/- 2.0 g

Resolution = 20 bits

The simulated quantization step obtained from the MATLAB model is:

0.000037409 m/s^2

## 6. SNR Calculation

The estimated signal-to-noise ratio is calculated as:

SNR(dB) = 20*log10(True Signal RMS / Total Error RMS)

where:

True Signal RMS = RMS of the ideal acceleration signal

Total Error RMS = RMS difference between measured and true acceleration

## 10. Simulation Procedure

1. Load the common DIA-TISSUE simulation parameters.
2. Select Model A.
3. Generate the true mechanical acceleration response.
4. Define the simulated sensor configuration.
5. Calculate the sensor noise RMS.
6. Add sensor bias.
7. Add random sensor noise.
8. Apply the sensor range limitation.
9. Apply the 20-bit quantization.
10. Calculate the measurement error.
11. Calculate the total error RMS.
12. Calculate the estimated SNR.
13. Calculate the sensor quantization step.
14. Generate the sensor simulation graphs.
15. Store the generated graphs in the results folder.

## 17. Inference

The experiment demonstrates that the mechanical acceleration response can be passed through a simulated accelerometer model while accounting for important sensor characteristics.

The sensor model introduces realistic engineering factors such as:

- Measurement noise
- Sensor bias
- Finite resolution
- Quantization
- Measurement range
- Bandwidth

The obtained SNR of 55.68 dB indicates that, under the selected simulation assumptions, the modeled acceleration signal remains distinguishable from the total measurement error.

This provides an engineering-level assessment of the sensor requirements for the DIA-TISSUE system.

The result does not establish clinical sensor performance or diagnostic capability.

## 18. Limitations

1. The sensor is simulated rather than physically tested.
2. The sensor parameters are assumed simulation values.
3. The experiment does not use real ADXL355 hardware data.
4. Sensor noise is represented using a simplified noise model.
5. Real sensor noise may include additional frequency-dependent components.
6. Real-world temperature effects are not modeled.
7. Sensor axis misalignment is not modeled.
8. Cross-axis sensitivity is not modeled.
9. Mechanical mounting effects are not modeled.
10. Experimental hardware validation is required before drawing conclusions about an actual sensor.

## 19. Conclusion

The DIA-TISSUE ADXL355-like sensor simulation was successfully implemented.

The simulation used a +/- 2.0 g range, 20-bit resolution, 150 Hz bandwidth, 0.000250 m/s^2/sqrt(Hz) noise density, and 0.010000 m/s^2 bias.

The resulting true signal RMS was 6.388942 m/s^2, while the total error RMS was 0.010504 m/s^2.

The estimated SNR was 55.68 dB and the quantization step was 0.000037409 m/s^2.

The experiment demonstrates the effect of sensor characteristics on the measured mechanical acceleration and provides an engineering basis for evaluating sensor requirements in later stages of the DIA-TISSUE project.
